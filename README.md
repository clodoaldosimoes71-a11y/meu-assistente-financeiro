# meu-assistente-financeiro
Assistente financeiro pessoal desenvolvido em Python.
## Objetivo do projeto

Criar um assistente financeiro pessoal
integrado ao WhatsApp.

## Funcionalidades planejadas

- Registrar receitas.
- Registrar despesas.
- Organizar categorias.
- Gerar relatórios.
- Controlar orçamento mensal.
